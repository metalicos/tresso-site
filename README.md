# Tresso — сайт-візитка

Статичний сайт застосунку **Tresso** для iPhone (GitHub Pages): головна сторінка, політика конфіденційності, підтримка й умови використання — потрібні для публікації в App Store.

- Головна: `index.html`
- Privacy Policy URL (App Store Connect): `privacy.html`
- Support URL (App Store Connect): `support.html`
- Умови: `terms.html`

Без збирача й залежностей: HTML + CSS, шрифт Manrope (SIL OFL). Деплой — GitHub Pages з гілки `main`, корінь репозиторію.

Звернення користувачів — через [Issues](https://github.com/metalicos/tresso-site/issues).
